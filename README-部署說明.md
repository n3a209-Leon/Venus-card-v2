# Venus Card System v3.3.1

## 部署

請將本資料夾內的所有檔案與 `assets` 資料夾完整上傳到原網站根目錄，維持檔名與目錄結構，不要只替換 `index.html`。

必要檔案包含：

- `index.html`
- `sw.js`
- `manifest.json`
- `xlsx.full.min.js`
- `splash.jpeg`
- `icon-180.png`、`icon-192.png`、`icon-512.png`
- `icon-1024.png`、`icon-maskable-512.png`
- `assets/` 內全部主題素材

部署後保持網路連線。App 顯示「新版本已準備好」時，再按「立即更新」。v3.3.1 會核對 `index.html` 與 `sw.js` 的建置識別；若網站只上傳部分檔案，新 Service Worker 會拒絕安裝，避免混版。

## v3.3.1 懸浮膠囊修復

- 修正日蝕主題將底部五鍵導覽改回一般文件流，造成工具列被推到長頁面最底端的問題。
- 主題層不再覆蓋 App 直系元件的定位方式；頂部黏附、底部膠囊與撤銷按鈕各自維持原定位。
- 新增所有主題共用的最終定位保護，五鍵膠囊固定浮在 iPhone Home 指示條上方。
- 保留 54px 按鍵高度、原本左右內縮與精簡 safe area，不新增底部大片空白。
- 資料 schema 與所有操作功能不變，可由 v3.2.0／v3.3.0 直接升級。

## v3.3.0 介面一致性與幹部辨識

- 全部座號格改為每列平均伸展；最後一列人數不足時也會自動吃滿寬度，不再留下右側空區。
- 幹部區改為四欄資訊卡：左側固定座號，右側顯示 LIMU 職稱與本週 ×1／×2 狀態。
- 上方標題列依 LIMU／Venus OS 改為雙層結構：第一層為品牌、版本、同步、主題與帳號；第二層為滿寬班級切換。
- 左上角 `VENUS` 品牌可從任何分頁直接回到總覽首頁，並自動收合班級選單。
- iPhone 頂部 safe area、底部五鍵導航與底部 Home 指示條避讓方式維持不變。

## v3.2.0 日蝕奧德賽美術

- 啟動畫面改為高解析日蝕海岸女神主視覺，文字與載入提示由 App 疊加，不烙印在圖片內。
- iOS／PWA Icon 統一取自同一張 1024 主檔，另提供 Android maskable 安全區版本。
- 主題選單新增「🌘 日蝕」，新安裝預設使用；既有使用者仍保留原本選擇。
- 日蝕主題只在背景使用一次角色主視覺，卡片、邊框與導航不重複放人物，也不增加操作區空間。
- 底部五個導航圖示換成同一套 SVG 線性圖示，按鍵尺寸與位置不變。

## 從 v3.2.0 升級

1. 使用原本的 Google 帳號登入。
2. v3.2.0 的 UID 隔離雙槽快照、回收筒、流水帳、私人 Sheets 與日蝕美術會直接沿用。
3. 舊成績、獎卡、班級、範本與設定不會清除或重建。
4. 這一版只調整介面版面與導覽，不變更資料 schema。
5. Venus OS 與 LIMU 路徑仍永久唯讀；不會寫入、更新或刪除班級、分組、幹部及作業資料。

## 私人 Google Sheets

新連結預設使用 `spreadsheets.readonly` 私人唯讀授權，試算表可維持「限制存取」。第一次同步會彈出 Google 授權視窗。Firebase／Google Cloud 專案需啟用 Google Sheets API，OAuth 同意畫面需允許目前使用的 Google 帳號。

v3.0.0 已存在、未標記讀取方式的連結會先保留為公開連結相容模式；可在成績頁按「轉私人」。授權憑證只保留於本次 App 使用期間，不寫入本機快照或雲端資料。

## 新學年度轉換

「設定 → 同步 → 開始新學年度」會先同步並下載舊班完整封存，再建立 Venus Card 專用的新年度班級。可選擇帶入座號、工作名單、換卡門檻與常用範本；成績、舊紀錄、持卡數、Sheets 連結與回收筒不會帶入。若來源是 Venus OS 班級，也只會建立新的 Venus Card 班級，不回寫 Venus OS。

## 儲存警告

若裝置空間、Safari 儲存或隱私模式造成寫入失敗，App 會顯示不可略過的警告，並暫停登出、換版與重新整理。請先按「重新嘗試儲存」；必要時下載緊急備份。
