# Venus Card System v2.8.1 部署說明

本版以 v2.8.0 為基底，保留全部獎卡、成績、抵免、同步、救援、報表、
開場圖、App Icon 與四套主題；總覽的個別座號資訊、顯示欄位及計算
邏輯沒有改動。

## 主題視覺

- 慕夏主框、卡框與彈窗花飾均保持素材原始比例，不再使用拉伸式
  `border-image`。
- 主框只出現一次；長頁面以細金線延續，不重複人物、鳶尾與角花。
- 星雲主題新增非重複的星軌側框、角落星芒與內側細線。
- 裝飾全部不接收觸控，也不改按鍵、座號卡及任何操作區尺寸。

## 底部導覽與 iPhone 版面

- 根容器改用與 LIMU v20.19 相同的自然頁面高度。
- 移除 `100dvh + overflow:hidden` 鎖高組合，避免 iOS 將較短的
  WebKit viewport 變成底部閒置區。
- 底部操作列為 48px，額外緩衝最多 2px。
- 五個按鍵仍保留至少 44px 觸控高度。
- 主內容只預留一次底部導覽高度。
- 底部彈窗仍使用完整安全區，避免確認鍵被 Home 指示條遮住。
- 狀態列恢復 `black-translucent`，主題背景可延伸到動態島後方。

## 班級管理（不修改 Venus OS）

- Venus OS 的 `users/{uid}/data` 路徑維持唯讀。
- OS 班級可在 Venus Card 內隱藏或恢復；不會刪除、改名或回寫 OS。
- 可新增 Venus Card 專用班級，並可改名、封存、恢復。
- 封存是可復原操作，不會刪除班級的座號、成績、獎卡或紀錄。
- Card 班級索引只寫入 `vc-card-users/{uid}/classes` 與本機備援。

班級管理入口：

1. 點左上角班級名稱，再點「新增／管理班級」。
2. 或到「更多 → 班級管理」。
3. 總覽「全班點數」標題右側也有「班級」快速入口。

## 部署

請將壓縮檔內全部檔案一起上傳到網站根目錄，不要只更新
`index.html`。部署後按「立即更新」，再確認頁首版本為 `v2.8.1`。

若 iPhone 仍執行舊版版面，請完全關閉 App 再開啟；若狀態列仍沿用
舊安裝設定，再移除原主畫面捷徑並由 Safari 重新加入一次。

`xlsx.full.min.js` 與 `LICENSE.xlsx.txt` 必須保留；`assets/` 內慕夏
素材也必須完整上傳。
